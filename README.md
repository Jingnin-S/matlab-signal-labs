# MATLAB Signal Processing Labs

MATLAB scripts and Live Scripts covering DFT/FFT, filters, windows, audio, and related experiments. Live Script source documents are preserved, with cached execution output cleared before publication. Reviewed PNG/JPEG assets are included with ancillary metadata removed.

Open `.m` or `.mlx` files in MATLAB and run individual experiments. Some scripts require signal-processing toolboxes or external inputs. Audio recordings, opaque `.p`/`.mat`/`.fig` data, archives, and cached dialing-signal plots are excluded; supply appropriate local input files before running those examples. Source paths have been made relative where needed.
